# 💌 Shake & Love

Una página web romántica y minimalista para pedirle a alguien que sea tu novia/novio.

## ¿Cómo funciona?

1. **El creador** abre la web y escribe su mensaje personalizado
2. Recibe un **enlace único** con su mensaje
3. Manda el enlace por WhatsApp, SMS, etc.
4. **La persona** abre el enlace y ve una escena con un pollito durmiendo sobre una caja
5. Debe **agitar el móvil** para despertar al pollito
6. La caja se abre y aparece el mensaje
7. Si dice **Sí**: ¡flores y confeti! 🎉
8. Si dice **No**: el pollito vuelve a dormir 💤

### Subir a GitHub Pages (gratis)
1. Crea un repositorio en GitHub
2. Sube todos los archivos
3. Ve a Settings > Pages > Source: "main branch"
4. Tu web estará en: `https://tu-usuario.github.io/tu-repositorio/`


## Características

- ✅ **Responsive** - Funciona en móvil, tablet y escritorio
- ✅ **Sin backend** - Todo funciona en el navegador
- ✅ **Personalizable** - Cada persona puede poner su mensaje
- ✅ **Interactivo** - Toca objetos, agita el móvil
- ✅ **Sin dependencias** - Solo HTML, CSS y JavaScript puro

## Tecnologías

- HTML5
- CSS3 (con animaciones)
- JavaScript vanilla
- URL parameters (para personalización)
- DeviceMotion API (para detectar sacudidas)
- Web Audio API (para sonidos)
